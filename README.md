# Web Demos

Small front-end and PHP experiments.

| Demo | What it shows | Stack |
|---|---|---|
| [`urdu-speech-to-text`](urdu-speech-to-text/) | Live Urdu (`ur-PK`) dictation in the browser with interim results; the transcript is saved server-side. | Web Speech API, JavaScript, PHP |
| [`chatbot-comparison`](chatbot-comparison/) | A single page for switching between embedded chatbot platforms. The Microsoft Bot Framework embed is done; Rasa, Dialogflow, IBM Watson and Wit.ai slots are stubbed. | HTML, CSS, JavaScript |
| [`php-crud`](php-crud/) | Create, read, update and delete records with PDO prepared statements, switching between two MySQL databases. | PHP, PDO, MySQL |

Run the PHP demos under any local PHP server (`php -S localhost:8000`) or XAMPP. The speech demo needs Chrome.
